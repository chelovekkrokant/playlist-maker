# Playlist Maker

Android-приложение для поиска музыки и управления медиатекой (создание плейлистов, добавление в избранное). Разработано на базе современного Android-стека: Jetpack Compose, Clean Architecture, Coroutines/Flow, Room и Koin.

---

## Основной функционал

- **Поиск треков**: интеграция с iTunes Search API, отображение плейсхолдеров для состояний загрузки, сетевых ошибок и пустого результата.
- **История поиска**: сохранение последних 10 запросов без дубликатов с возможностью быстрой очистки.
- **Экран плейлиста и трека**: просмотр обложек высокого разрешения, длительности, метаданных и информации об альбоме.
- **Медиатека**:
  - Добавление композиций в список «Избранное».
  - Создание кастомных плейлистов с названием и описанием.
  - Добавление треков в плейлисты.
- **Настройки**: переход к пользовательскому соглашению, возможность поделиться приложением и написать в поддержку.

---

## Стек технологий

- **UI**: Jetpack Compose, Material 3, Navigation Compose
- **Архитектура**: Clean Architecture (Data / Domain / Presentation), MVVM
- **Асинхронность**: Kotlin Coroutines, StateFlow, SharedFlow
- **Сеть**: Retrofit
- **Локальное хранилище**: 
  - Room (ORM, SQLite) + KSP для сущностей треков и плейлистов
  - Jetpack DataStore Preferences для истории поиска и настроек
- **Dependency Injection**: Koin
- **Загрузка изображений**: Coil

## Сборка и запуск

1. Клонируйте репозиторий:
