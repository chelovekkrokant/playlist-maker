# Playlist Maker

Учебное Android-приложение для поиска треков через iTunes Search API, сохранения избранных треков и управления плейлистами с использованием Room.

## Версии

| | |
|---|---|
| Kotlin | 2.0.21 |
| Compile SDK | 36 |
| Min SDK | 29 |

## Сборка и запуск

```bash
git clone https://github.com/chelovekkrokant/playlist-maker.git
```

Открыть папку в Android Studio → дождаться синхронизации Gradle → **Run → Run 'app'**.
