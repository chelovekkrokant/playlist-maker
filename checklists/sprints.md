# Playlist-maker-android-GayfutdinovAydar
Учебный проект по созданию мобильного приложения.

# Проблема
В курсе присутствует несоответствие названий спринтов и подписей к проектам.

Пример:
В окне программы "Введение в Compose" - спринт 5 во вкладке "Проверочная работа" есть пункт "Итоги спринта 3".

В связи с этим несоответствием названия веток созданы по названиям спринтов в основном курсе.

Так, спринту №5 соответствует проект №3, спринту №6 соответствует проект №4 и так далее.

- При нажатии на кнопки выполняется открытие экранов.

## Branch sprint-6 (проект спринта 4 "Продвинутый UI"):
- Сверстан SearchScreen.

- Созданы enum, PlaylistHost и реализованы переходы NavController.

## Branch sprint-7, sprint-7-fix (проект спринта 5 "Базовая современная архитектура"):
- Реализовано разделение на уровни согласно принципам clean-architecture.

- Реализован репозиторий поиска.
- Фильтрация выполняется в слое Data/Domain.
- Длительность треков форматируется в формате mm:ss.

## Branch sprint-8 (проект спринта 6 "Продвинутый UI"):
- Реализован и применен SearchViewModel.
- Обновлен SearchScreen с корректным отображением поиска (поиск в том числе по авторам песен).
- Во время загрузки отображается loader, при отсутствии найденных треков отображается сообщение.
- Приложение работает корректно.

## Branch sprint-9 (проект спринта 7 "FloatingActionButton и ModalBottomSheet"):
- Реализован экран плейлистов (`PlaylistScreen`) с кнопкой `FloatingActionButton` в правом нижнем углу.
- При нажатии на `FloatingActionButton` открывается всплывающая панель `ModalBottomSheet`.
- При нажатии на экран за пределами панели `ModalBottomSheet` — панель скрывается.
- Кнопка «Плейлисты» в главном меню теперь открывает экран плейлистов вместо Toast-уведомления.
- Экран встроен в единую навигацию через `NavHost` (`Screen.Playlist`).
- Состояние видимости панели управляется локальным стейтом (`remember { mutableStateOf(false) }`).

## Branch sprint-10 (проект спринта 8 "Многопоточность"):
- Настроена навигация между главным экраном и экранами Songs, Playlists, Favorites.
- Реализован экран Favorites со списком треков, добавленных в «Избранное».
- Реализован экран создания нового плейлиста с полями для имени и описания и кнопкой «Создать».
- На экране Playlists реализован FloatingActionButton для перехода на экран создания плейлиста.
- Реализован экран Track details с детальным описанием трека.
- Настроена навигация с экрана Songs на экран Track details при клике на трек.
- На экране Track details размещены кнопки «Добавить в избранное» и «Добавить в плейлист».
- При нажатии на «Добавить в избранное» у трека изменяется значение поля favorite.
- При нажатии на «Добавить в плейлист» отображается ModalBottomSheet со списком плейлистов; при выборе плейлиста треку присваивается соответствующий playlistId.

## Branch sprint-11 (проект спринта 9 "Сеть"):
- Подключён Retrofit + OkHttp; реализован `RetrofitNetworkClient` и `ITunesApiService` для поискового запроса к iTunes API.
- Реализован `TracksRepositoryImpl`: маппинг DTO → доменный `Track`, форматирование длительности `trackTimeMillis` в `mm:ss`.
- `SearchViewModel` обрабатывает все состояния поиска: загрузка (`Loading`), пустой результат (`NothingFound`), сетевая ошибка / ошибка сервера (`Error`), успешный результат (`Content`).
- На экране поиска отображаются плейсхолдеры «ничего не найдено» и «ошибка сети» с кнопкой «Обновить», повторно выполняющей последний запрос (`retry()`).
- Обложки треков загружаются через Coil (`AsyncImage`) с заглушкой `ic_music` на время загрузки и при отсутствии изображения.
- Кнопка «Очистить» в строке поиска очищает запрос, скрывает клавиатуру и убирает список треков.
- Реализован экран детального просмотра плейлиста (`PlaylistScreen`): обложка-плейсхолдер занимает половину экрана, ниже — название, описание, суммарное время и список треков.
- Реализована полная навигация: список плейлистов → экран плейлиста → детали трека; кнопка «Назад» на каждом экране возвращает к предыдущему.

## Branch sprint-12 (проект спринта 10 "Хранение данных"):
- Подключена библиотека Room (v2.7.2) через KSP; созданы `TrackEntity`, `PlaylistEntity`, `TracksDao`, `PlaylistsDao`, `AppDatabase`.
- Плейлисты и треки (избранное, треки в плейлистах) сохраняются в базе данных Room и восстанавливаются после перезапуска приложения.
- Реализован `DomainTracksRepositoryImpl`: полная поддержка избранного и плейлистов через Room вместо `DatabaseMock`.
- `PlaylistsRepositoryImpl` переписан на Room: `getAllPlaylists` и `getPlaylist` возвращают плейлисты вместе с треками через `combine`.
- История поиска сохраняется в DataStore Preferences через `SearchHistoryPreferences`: не более 10 запросов, без дубликатов, последний запрос в начале списка.
- `DatabaseMock` удалён — все данные хранятся в постоянном хранилище.
- Внедрён Koin (v3.5.6) для dependency injection: `databaseModule`, `networkModule`, `repositoryModule`, `viewModelModule`; `Creator.kt` удалён.
- Добавлен класс `PlaylistMakerApp : Application` — точка инициализации Koin и DataStore.
- ViewModels переведены на конструкторное внедрение зависимостей; навигация использует `koinViewModel`.
- Реализован экран «Избранные треки»: список треков в стиле SearchScreen, пустое состояние с иконкой и текстом «Ваша медиатека пуста», переход на детали трека по клику.
- На экране деталей трека обложка загружается через Coil в разрешении 600×600; иконка «Добавить в плейлист» заменена на `outline_library_add_24`.

## Branch sprint-14 (проект спринта 12 "Доработка проекта и финальное задание"):
- Реализован переход на главный экран и создана стрелка назад не по шаблону согласно требованию 5 спринта "Реализуйте переходы на экран трека и на главный экран по кнопке назад — вы уже делали это на экране поиска" и пункту из чек-листа "Наверху экрана отображена иконка возврата на предыдущий экран."
- Добавлена функциональность добавления картинки в качестве обложки плейлиста.
- Реализовано корректное добавление трека в избранное и удаление из избранного. Корректно отображается статус нахождения в избранном.
- Отображается плейсхолдер обложки если не загружена обложка трека.
- Реализовано удаление трека из плейлиста при долгом нажатии с уточняющим вопросом.
